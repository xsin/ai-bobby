## 维护规则

- PRD / tech 是整体产品设计与技术方案，不是代码变更日志；代码迭代时只做局部修订/补充，不要重写成实现摘要。
- 代码迭代必须同步更新对应文档；文档描述与代码不一致时，以代码为准并立即改文档。
- 人类阅读文档只保留当前状态，**不写变更日志、修订记录、上一版说明**。
- 历史决策与进度只放在 [handsoff.md](../handsoff.md)（agent 记忆）。
- 不把商业价格、合同、客户信息写进公开文档；这些在私有 biz 仓库。
