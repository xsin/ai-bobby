# Prototype

按产品面分的静态可点击原型：

| 目录 | 内容 | 入口 |
|---|---|---|
| [`desktop/`](./desktop/) | 桌面控制面板（左侧栏多页、历史/备份恢复、关于 ZEO、可拖动头像） | [`desktop/index.html`](./desktop/index.html) |
| [`website/`](./website/) | 落地页视觉稿（WebGL / GLSL / SVG / Canvas） | [`website/index.html`](./website/index.html) |

这些都是**视觉/交互稿**，不是生产实现。生产代码在 `apps/` 与 `packages/`。
