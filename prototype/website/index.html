04 / LOCAL-FIRST

            
Yours.
Not the cloud's.

          

          

            AI Bobby 只监听回环地址；API Key、账号、模型目录都在本机。
            没有账号系统，没有云端会话历史。
          

        

        

          

            ◉
            
127.0.0.1 only

            
浏览器 Origin 直接 403；端口不暴露到局域网。

          

          

            ⌁
            
Keys stay local

            
随机 API Key 落盘 0600；日志与状态只出现掩码。

          

          

            ↻
            
Failover, not failure

            
单账号 429 冷却换号；流式开始后不中途切换。

          

          

            ◌
            
No telemetry

            
没有产品分析 SDK；更新检查只请求 latest.json。
